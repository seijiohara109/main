# フロア設定資料

作業分担: 図面（フロアプラン作成・席配置・ボード実装）は**制作部（隼人）担当**。
本資料は**立地・建物スペック・世界観設定**のみを扱う。図面作業への申し送りは §5 に集約。

---

## 0. 確定している前提

| 項目 | 値 |
|---|---|
| 会社の年商 | 5億円 |
| コアメンバー個人の年収 | 1億円 |
| 空間の性質 | オフィス／仕事場 |
| コア人数 | 5〜6名（剛・玲子・湊・神谷・隼人 ほか） |

---

## 1. 規模の逆算

コア5〜6名、全員が高単価の参謀型。一般オフィスの原単位（3〜4坪/人）では設定が嘘くさくなるため、**8〜10坪/人**で取る。

| 項目 | 数字 |
|---|---|
| 専有面積 | 55坪（約182㎡） |
| 都心一等地の賃料 | 坪3〜5万円/月 |
| 年間賃料 | 約1,800〜3,600万円 |
| 年商5億に対する比率 | **4〜7%** |

### この数字が設定として意味すること

年商5億に対して賃料7%は**かなり攻めた比率**。一般的な適正値（5%以下）の上限に張り付いている。

これは弱点ではなく、この組織のキャラクターそのものとして使う ——
**身の丈より一段いい場所に、意図して住所を置いている組織**。
看板を出さない代わりに、住所で信用を買っている。

---

## 2. 立地

### 検討した3案

**A. 丸の内・大手町**
権威は最強。ただし大箱ビルは受付も共用部も全部他人のもので、「ワンフロア丸ごと」の専有感が出ない。55坪では器が大きすぎ、少数精鋭という設定と噛み合わない。

**B. 虎ノ門・六本木**
速度と可視性。ただし「見られる場所」であり、人の出入りが業界に筒抜けになる。参謀組織の秘匿性と相性が悪い。

**C. 南青山・番町・麻布あたりの低層ビル** ← **採用**

### 採用案の中身

- 住所は一等地、建物は**9階建ての小箱**
- ワンフロア専有が55坪という現実的な面積で成立する
- エレベーターを降りたらそこがもう自社、という構造が作れる
- **看板なし。表札のみ**
- 「探して来た人しか辿り着かない」が成立する唯一の選択肢

---

## 3. 階 — 最上階を取らない

**9階建ての8階。**

高層階＝権力、という記号は手垢がついている上に、実務的にも動線が長くて人の出入りが目立つ。ここは逆を取る。

最上階（9F）は**資料庫・サーバー・屋上設備**に充て、人は入れない。

> **「一番上を取れるのに、取っていない」**

この一手が、この組織のキャラクターを一行で説明してくれる。
8階なら窓の外に街の輪郭が見えて、かつ地上と地続きの感覚も残る。

### 階層構成

| 階 | 用途 |
|---|---|
| 9F | 資料庫・サーバー・屋上設備（人は入らない） |
| **8F** | **本フロア（専有）** |
| 2〜7F | 他テナント |
| 1F | エントランス（無人・カードキー） |
| B1 | 機械式駐車場 |

## 4. 建物スペック（図面作業用の実数）

| 項目 | 値 |
|---|---|
| 専有部形状 | 東西 13.0m × 南北 14.0m（≒182㎡ / 55坪） |
| 天井高 | 2,800mm（OAフロア上端から） |
| OAフロア | 100mm |
| 階高（スラブ間） | 4,100mm |
| 窓 | **南面・東面・西面**に腰高450mmからの連窓 |
| 北面 | **隣地に接し、窓なし＝全面が壁** |
| エレベーター | 定員9名×1基。8階専有部はカードキー制御 |
| 非常階段 | 北西コーナー |
| 竣工 | 築15年程度・スケルトン渡しで内装フルリノベ |

### 北面が窓なしであることの重要性

低層ビルが隣地に接している場合、これはごく自然な条件。そしてこれが
**「北壁がボード面である」ことの物理的な理由**になる。

設定として「なんとなく北にボードを置いた」ではなく、
**そこにしか置けないから置いてある**、という筋の通り方をする。

---

## 5. フロア構成の骨格 — 図面作業（隼人）への申し送り

以下は既に出ている4点の指示から読み取れる幾何。図面化の際の参考として。

```
        ┌─────── 北壁：スケジュールボード ───────┐
        │        （進行ボード / やることリスト）    │
        │                  ↑                      │
        │        玲子 ←─ 通路 ─→ 湊               │  中核エリア
        │        （東）        （西）             │  = 日々の進行
        │                  ↑                      │
        │                 剛                      │
        └─────────────────────────────────────────┘
        ┌── 神谷ゾーン：北側パーテーション ────────┐
        │   ボード（事業計画 / プロジェクト別タスク）│  = 中長期
        └─────────────────────────────────────────┘
                    南面・東西面 = 窓
```

### この骨格が成立している理由

**1. 北壁がボード面なのは実務的に正しい**
北側は直射日光が入らないので、ディスプレイもホワイトボードも一日中読める。
加えて §4 のとおり北面はそもそも窓が取れない。窓は南と東西に振る。

**2. 剛の動線が意味を持つ**
玲子と湊の間を通ってボードへ抜ける、という配置は、統括参謀が盤面を見に行くたびに
**必ず二人の視界を横切る**ことを意味する。声をかけずに情報が同期する。
偶然ではなく、設計されたレイアウトとして説明できる。

**3. 二層構造になっている**
中核エリア＝日々の進行、神谷ゾーン＝事業計画という中長期。
ボードが2枚あるのは冗長ではなく、**時間軸が違う**から。

**4. 1フロア完結**
全員が同じ階にいる＝階層で情報を分断しない。
ビルの階数を組織の序列メタファーにしない、という選択。

---

## 6. 設定として効くディテール（まとめ）

| ディテール | 効いている理由 |
|---|---|
| 看板を出さない | 住所で信用を買っているので、掲示する必要がない |
| 最上階を取らない | 取れるのに取らない＝見せない権力 |
| 北壁がボード面 | 窓が取れない面を、最も情報密度の高い面に転換している |
| 剛の動線が二人を横切る | 情報同期が建築で担保されている |
| 賃料比率が上限に張り付く | 身の丈より一段上に意図して置いている |
| ワンフロア完結 | 参謀組織はフラット、階段で情報を切らない |
